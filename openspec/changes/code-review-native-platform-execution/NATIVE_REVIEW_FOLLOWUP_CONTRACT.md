# Native review regression contract

## Project range evidence

A native project range review SHALL pass the authenticated native analyzer-version
map and platform identity from both snapshot results into report activation.
If the two sides disagree on platform or version map, the review SHALL remain
incomplete rather than relabeling a result as Linux evidence.

## Ordinary source imports

For a selected native Python file, the immutable worker snapshot SHALL include
bounded in-project Python import context needed by type and architecture analyzers.
Only explicitly selected files are analyzer targets. Paths escaping the source
root, case-fold collisions, mutable captures and oversized inventories SHALL
fail closed. Host secrets unrelated to Python source SHALL not be staged.

## Managed tool deadline

An admitted managed tool request SHALL use its validated timeout, including
values above two minutes up to the four-minute protocol maximum. The controller
SHALL not shorten an admitted timeout by substituting its default analyzer wait.

## Managed diagnostic identity

Every managed tool that reports file paths SHALL rebind its structured or
line-oriented paths from the exact tool snapshot into logical project-relative
paths before a later analyzer stage replays the result. Paths outside the tool
snapshot, malformed relative paths and path collisions SHALL make the member
incomplete. The replayed analyzer SHALL retain a finding for a real diagnostic
on a selected file even when its immutable project root differs from the tool
stage root.

## Linux regression: bounded OCI decompression

The ordinary-user full Linux guest exposed a controller allocation failure:
reading the complete signed 4 GiB allowance requests that allocation even when
the actual layer is smaller. Decompression SHALL use reads of at most 1 MiB,
retain the exact signed byte bound and reject one-byte overflow. Both layer
digests SHALL verify before filesystem application; file counts, duplicate
paths and whiteout checks SHALL retain their current behavior. No worker, VM,
namespace, timeout or signed artifact limits change to satisfy this regression.

## Native pytest coverage coordinates

Complete native pytest coverage SHALL use one snapshot coordinate system for
selected tests, configured test roots, support helpers and reviewed production
files. Controller-validated logical roots SHALL rebind only below the admitted
immutable native snapshot. Test/support exclusion SHALL retain Linux semantics;
missing or low production coverage, escaping configuration roots and receipt
conflicts SHALL still reject complete evidence. No threshold or provenance changes.
