## Why

A completed full native review can produce a report larger than the existing bounded reader admits. Its public projection then lacks source-checked finding identities and per-side diagnostic categories needed to investigate the failure.

## What Changes

Add an opt-in, bounded producer-owned diagnostic sidecar for one explicitly authorized immutable public source pair. Retain authoritative per-side results before report serialization. Add an isolated manual diagnostic mode to the existing customer workflow, using a separately reviewed preview signed by the unchanged established CI signer. Ordinary workflow paths and required assurance remain unchanged.

## Impact

The diagnostic preview derives from verified signed 0.51.2 source. It is not a release, baseline upgrade or accepted reviewer. No raw messages, private paths, parameter identifiers or stderr become public. Unclassified details remain unavailable. One supplemental full run is authorized; remediation, repeated runs, merge and registry publication are excluded.
