- `ai-bloat.loc-vs-complexity` in `target_launch.target_command`: retain the explicit bubblewrap argument vector. Mount order, descriptor paths and environment-clearing order define the isolation boundary; a compact generated mapping would make that boundary harder to audit. The function adds a single read-only domain bind and does not introduce duplicate resolution logic. First-entry isolation and all five nested-domain subprocess cases pass.

Splitting this one fixture into single-use factories would obscure which production bytes are executed without reducing behavior or duplication.
