## Shared project contract

Reuse ProjectPlan and the released selection, findings and verdict logic.
Explicit configuration wins over verified active context and unambiguous
metadata. Acquisition catalogs describe SpecFact runtimes, never customer
repositories. Use authentic pinned managers on disposable snapshots; preserve
locks, constraints, groups, extras and environments. Build hooks and tests are
project code and cannot execute with acquisition credentials or network access.
Keep pytest labelled `project-origin-v1` with protected-review restrictions.

## Boundary feasibility before integration

Evaluate Windows mechanisms against the shared startup and managed-process
contract. Availability of an API is not acceptance. Prove that no worker runs
project code before ownership and confinement, cannot create unmanaged workers
or delegate execution, and dies when its invocation owner disappears. Enforce
resource limits, five-second cleanup and 100 repetitions of lifecycle races.
Admit native extensions and executable identities from verified artifacts or
inventoried local environments without expanding worker permissions.

## Physical and virtual acceptance

Matching-architecture full VMs and physical computers are equivalent acceptance
environments when required kernel capabilities and ordinary-user protections
pass. Record exact OS/kernel, CPU architecture, ABI, artifact digest, capability
results and VM/emulation settings. An optional UTM x86-64 emulated guest on an
ARM64 Mac supports debugging; native x86-64 CI VMs establish lifecycle/resource
acceptance. An ARM64 guest translating x86-64 apps does not establish this
target. WSL/Docker prove Linux behavior only. Hosted Windows administrator and
UAC-disabled defaults do not satisfy ordinary-user installation acceptance;
the harness must establish and record the intended user/protection configuration.

## Distribution and rollback

Verify immutable platform/ABI/policy-bound metadata and final payload bytes
before extraction, execution and offline reuse. Separate publisher manifest
authentication from OS trust/installation evidence. Signing keys remain in
CI/CD. Require clean installation, first acquisition, offline reuse, interrupted
and concurrent preparation, paths/Unicode, plugins, coverage, native extensions,
all ten analyzers and four manager suites before advertising support. Withdraw
only the affected Windows publication on rollback and preserve Linux/macOS evidence.
